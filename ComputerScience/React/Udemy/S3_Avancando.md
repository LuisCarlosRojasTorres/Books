## V035 Imagenes publicas no React

- Ficam na pasta `public`
- Tag `img` e com o `/path.jpg`  

``` jsx
function App() {  
  return (
    <div>
      <h1>S3 More content!</h1>
      <img src="/totodile.png" alt="Placeholder" />
    </div>
  )
}

export default App
```
